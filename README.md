# HOD Approval System

A full-stack web application for managing academic approval workflows for faculty, Heads of Department (HOD), and administrators.

## Project Structure

- `frontend/` — React, TypeScript, and Vite user interface
- `backend/` — Node.js, Express, and TypeScript API

## Live Demo

[Open HOD Approval System](https://hod-approval-system.vercel.app)

## Running Locally

Install dependencies separately in the `backend` and `frontend` folders:

```bash
cd backend
npm install
```

Then in a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Configure the backend environment variables before starting the API.
